# oxabl-cache-crypto

Client-side cryptography for the oxabl-cache remote compile cache: key hierarchy, lookup ids, seal and open, signatures and the member roster. The server never links this crate.

Part of [oxabl-cache](https://github.com/oxabl-project/oxabl-cache), a zero-knowledge remote compile cache for [oxabl](https://github.com/oxabl-project/oxabl). Licensed under MIT.
