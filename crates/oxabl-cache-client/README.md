# oxabl-cache-client

Client library for the oxabl-cache remote compile cache. It looks up, fetches, verifies and installs compiled artifacts, and stores new ones, treating every failure as a miss.

Part of [oxabl-cache](https://github.com/oxabl-project/oxabl-cache), a zero-knowledge remote compile cache for [oxabl](https://github.com/oxabl-project/oxabl). Licensed under MIT.
